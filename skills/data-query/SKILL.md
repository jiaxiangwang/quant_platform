# 数据查询

## 工作流

1. 明确业务口径、标的、字段、频率、时间区间和期望行数。
2. 先调用数据语义层检索表、字段、关系、指标口径和已验证 SQL；不要在普通知识库中扫描全部数据库表。
3. 调用 `knowledge_search` 补充 Pilot SDK、平台限制和业务术语。
4. 只生成只读、可审计且受结果行数限制的查询；禁止根据猜测使用表名或字段名。
5. 通过服务端数据 Tool 执行，让平台注入 token，Agent 和业务代码不接触数据库账号。
6. 返回数据时同时说明时间、单位、空值、数据源和口径；查询失败时保留错误类型和任务 ID，不输出敏感堆栈。

## 安全约束

- SQL 必须经过服务端解析和白名单校验，不能只靠字符串过滤。
- 默认禁止 DDL、DML、多语句、注释绕过和不受限全表扫描。
- 大结果集使用服务端分页或文件交付，不能绕过平台硬限制。
