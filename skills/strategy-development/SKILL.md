# 策略开发

## 工作流

1. 提取标的、数据频率、时间区间、方向、指标、参数、成本和风险约束；缺少会改变策略含义的信息时先询问。
2. 调用 `knowledge_search` 检索指标定义、策略案例、平台规范和准确的 Quant SDK 用法。
3. 只使用知识库或正式 SDK 文档中存在的方法；无法确认接口时保留明确的集成点，禁止猜测 API。
4. 从 `strategy_template.py` 开始生成最小可运行代码，确保不使用未来数据，并为参数约束和信号边界添加测试。
5. 先在独立 Sandbox 做语法、导入和小样本测试，再进入回测 Skill。
6. 输出代码版本、关键假设、未确认项和验证结果。

## 约束

- 不在代码、日志或结果中暴露 token、数据库账号等凭据。
- 不直接执行生产交易；交易执行必须使用独立、鉴权的业务 Tool。
- 新增第三方依赖前需确认内网制品可用性和许可证。
- 标的或字段含义不明确时不得默认为常见股票口径。
